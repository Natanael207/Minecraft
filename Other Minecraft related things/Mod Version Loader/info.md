# Was macht der Mod Version Loader
Der Mod Version Loader kopiert die Mods von dem Ordner: 
`%appdata%\.minecraft\modsVersionen\[Version]`

In den Ordner:
`%appdata%\.minecraft\mods`

Dies bewirkt, dass man alle Mods von einer Version in einem modsVersionen Ordner haben kann und sie kurz vor dem Start über den Minecraft Launcher in den mods Ordner kopieren kann.
So muss man nicht den Ordner hervorsuchen um die Mods manuell zu kopieren.
